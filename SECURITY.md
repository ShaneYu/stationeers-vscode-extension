# Security policy

## Supported versions

Security fixes are provided for the latest published version of the extension.
Users should update to the newest available release before reporting a problem
that may already have been fixed.

## Report a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use the repository's
[private vulnerability reporting](https://github.com/ShaneYu/stationeers-vscode-extension/security/advisories/new)
form. Include:

- the affected extension version and platform;
- a clear description of the impact;
- reproduction steps or a proof of concept;
- any suggested mitigation; and
- whether the issue is already public.

If private vulnerability reporting is unavailable, contact the repository
owner through their GitHub profile and ask for a private reporting channel
without including exploit details in the initial message.

Reports will be acknowledged as soon as practical. A fix and coordinated
disclosure timeline will depend on severity, reproducibility, and Marketplace
review times.

## Scope

Security concerns may include the extension client, the bundled native language
server, packaging and update integrity, dependency vulnerabilities, or unsafe
handling of IC10 source text.

Ordinary bugs and feature requests belong in
[GitHub Issues](https://github.com/ShaneYu/stationeers-vscode-extension/issues).
