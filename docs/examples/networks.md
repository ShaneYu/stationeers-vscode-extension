# Multi-IC networks

The shared-network template demonstrates two ICs exchanging state over a
source-controlled cable network. One program publishes or writes a value and a
second program consumes it through its configured channel.

Debug both housings in one session to see each IC as a thread. Use **IC10: Step
World Tick** when you need game-like coordinated scheduling; single-instruction
stepping is useful for inspecting one program in isolation.
