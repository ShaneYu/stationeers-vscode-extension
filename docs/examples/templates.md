# Template catalogue

The extension includes reusable environments and programs for common patterns.
Run **IC10: Create Environment from Template** to choose one and preview the
destination before files are written.

Current templates include:

- One-door and two-door airlocks
- Filtration and temperature/pressure control
- Solar tracking
- Batch production
- Vending chute handshakes
- Shared multi-IC networks
- Pure Lua libraries and full Lua-chip scenarios
- Mixed IC10/Lua workspaces

The source templates live in [`templates/`](https://github.com/ShaneYu/stationeers-vscode-extension/tree/main/templates)
and are copied into the extension package under `packages/vscode/templates`.
