# IC10 language support

The toolkit follows the official IC10 instruction model while adding editor
intelligence around the program. It understands labels, `define` declarations,
`alias` declarations, registers, device targets, pins, constants, enums,
`HASH`/`STR` macros, and relative branches.

are conservative when a program cannot yet be resolved unambiguously.
