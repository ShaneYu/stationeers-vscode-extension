# Support

## Before reporting a problem

1. Update to the latest version of Stationeers IC10.
2. Confirm that the affected file uses the `.ic10` extension.
3. Run **IC10: Restart Language Server**.
4. Open **View: Output** and select **Stationeers IC10**.
5. If a custom `ic10.server.path` is configured, temporarily clear it and
   retry with the bundled server.

## Bug reports and feature requests

Use [GitHub Issues](https://github.com/ShaneYu/stationeers-vscode-extension/issues).
Include the extension version, editor version, operating system and
architecture, a minimal IC10 example, and relevant output-channel messages.

Set `ic10.trace.server` to `messages` or `verbose` only when protocol details
are needed. Review traces before sharing because they can contain source text.

## Security reports

Do not report suspected vulnerabilities in a public issue. Follow the
[security policy](https://github.com/ShaneYu/stationeers-vscode-extension/blob/main/SECURITY.md).

## Scope

Support is provided on a best-effort basis for the latest release on the
platforms listed in the extension README. General Stationeers gameplay,
hardware, modding, and IC10 program-design questions are outside the extension
support scope unless they reveal a language-tooling defect.
